`config.js` mantiene el cliente `dental` separado de F&F, Ayden y otros negocios. Coordenadas verificadas centran el mapa; `google.resolvePlaceId: true` permite resolver el ID mediante el servidor al activar Places. Nunca se inventa un Place ID. Reseñas/fotos usan los endpoints originales y carruseles compartidos con traducción y créditos; un snapshot sólo admite comentarios reales con fecha visible.

El calendario completo `../../booking.html?client=dental&lang=nl` y el formulario compartido están en modo demo: agradecen la prueba sin crear eventos ni enviar datos. Modo API, claves privadas y agenda propia quedan preparados para activación posterior. No pedir datos clínicos mediante este formulario general.

La ilustración es conceptual y no una fotografía de la práctica. Página compacta NL/EN, tipografía grande y encuadre estable entre idiomas. Fuentes en `config.js`; verificaciones en los tests de sectores/contacto.
